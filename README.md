# Лаборатори 1: Playwright автоматжуулсан тест ба Trace нотолгоо

- Оюутны нэр: Т.Төгөлдөр
- Оюутны код: B242270050
- Хөтөч: Chromium
- Playwright хувилбар: 1.65.1

## Гүйцэтгэсэн ажил ба тестийн үр дүн

SauceDemo вэб аппликейшн дээр Chromium хөтөч ашиглан нэвтрэх хуудасны харагдац, буруу нууц үгийн алдааны мессеж болон сагсанд бараа нэмэх, гарах урсгалыг шалгасан тестүүдийг ажиллуулж амжилттай давлаа. Тестийн `mytest.spec.ts` файлд алхам бүрийн үйлдэл болон шалгалтыг тайлбарласан комментуудыг оруулсан. Нотолгоо болгон амжилттай гүйцэтгэлийн trace файлууд, HTML тайлан болон санаатай унагаасан тестийн trace файлуудыг `evidence/` хавтаст хадгалсан.

## Playwright болон Selenium харьцуулалт (өөрийн ажиглалт)

Playwright ашиглан тест бичихэд хөтчийн тохиргоо болон автомат хүлээлтийн (auto-waiting) механизм нь тестийг илүү тогтвортой, хурдан ажиллуулахад тусалсан. Элемент болон сагсны тоолуур зэрэг төлөвийн өөрчлөлтийг шалгахад илүү урт хүлээлтийн код бичих шаардлага бага гарсан нь практикт ихээхэн амар байлаа. Мөн `--trace on` горим ажиллуулахад алхам бүрийн төлөв, дэлгэцийн зураг болон алдааны шалтгааныг `trace.zip` файл дотроос харах боломжтой нь тест унасан тохиолдолд шалтгааныг хурдан олоход дөхөм болсон. Үүний зэрэгцээ Playwright-ийн суурилуулсан HTML тайлан нь тестийн үр дүнг нэг дороос ойлгомжтой хянахад тохиромжтой санагдсан. Харин уламжлалт Selenium-ийн хувьд хөтөч болон драйверын уялдаа, хүлээлтийн зохицуулалтад нэмэлт тохиргоо их шаарддаг нь анзаарагдсан. Ерөнхий дүгнэлтээр богино хугацаанд найдвартай UI тест бичиж, алдааг шинжлэхэд Playwright илүү цэгцтэй, орчин үеийн туршлагыг өгч чадлаа.

## Нотолгооны файлууд

- `evidence/passed-traces/` — Амжилттай ажилласан тестийн trace файлууд.
- `evidence/html-report/` — Playwright HTML тестийн тайлан.
- `evidence/failed-trace/` — Санаатай унагаасан тестийн trace нотолгоо.
