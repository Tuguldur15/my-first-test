\## 1\. Гүйцэтгэсэн даалгаврын хураангуй
SauceDemo (\`https://www.saucedemo.com\`) вебсайт дээр Playwright фрэймворк ашиглан 3 бие даасан UI автомат тест бичиж гүйцэтгэв:
1\. \*\*Амжилттай нэвтрэх ба Logout тест:\*\* \`standard\_user\` хэрэглэгчээр нэвтрэн \`Products\` гарчиг болон URL баталгаажуулж Logout хийсэн.
2\. \*\*Сөрөг тест:\*\* Буруу нууц үг оруулах үед системээс \`Username and password do not match\` алдаа мэдээлж буйг шалгасан.
3\. \*\*Сагслах үйлдэл:\*\* Бараа сагсанд нэмэхэд тоолуур \`1\` болж шинэчлэгдэж буйг баталгаажуулсан.

\## 2\. Playwright ба Selenium харьцуулалт (Ажиглалт)
Playwright болон Selenium нь хоёулаа вэб автоматжуулалтын хэрэгслүүд боловч дараах давуу талуудтай:
1. **Автомат хүлээлт (Auto-waiting):** Элемент бэлэн болох, харагдах, идэвхжих хүртэл автоматаар хүлээдэг тул гараар `sleep` эсвэл урт `wait` бичих шаардлага багасч, тест тогтвортой болдог.
2. **Олон хөтчийн дэмжлэг ба орчин үеийн архитектур:** Chromium, Firefox, WebKit хөтчийг нэгдсэн API-аар удирдаж, хөтөчтэй шууд холбогддог тул ажиллагаа харьцангуй хурдан байдаг.
3. **Хүчирхэг locator ба assertion:** Хэрэглэгчийн харах өнцөгт ойр `getByRole`, `getByPlaceholder`, `getByText` зэрэг локаторууд болон автоматаар дахин шалгадаг `expect` (`toBeVisible`, `toHaveText`) баталгаажуулалттай.
4. **Суурилуулсан Trace Viewer ба тайлан:** Тестийн явцын зураг, сүлжээний хүсэлт, алдааны төлөвийг алхам бүрээр нь `Trace Viewer` болон `HTML Report` дээр хялбар шинжлэх боломжтой.
